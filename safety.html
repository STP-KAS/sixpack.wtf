Safety

This site is a till and a map. It is not a wallet. It does not hold keys.

Never paste a seed, private key, or wallet password into this site — or any website. sixpack.wtf has no seed field. If you see one, you are not on this page. Close the tab.

Permission

  • Log in is top-right. Nothing connects until you click.
  • Kasware / Kastle then show their popup (usually the extension, top-right). Read the origin. Decline is fine.
  • This page never calls requestAccounts on load.
  • Session storage keeps a public address only. That is not a key. Log out clears it.

If something feels wrong

  • Seed box, “import wallet”, or a PDF of 12/24 words → close the tab. That is not us.
  • A Kasware popup for an origin that is not sixpack.wtf or 127.0.0.1 → reject.
  • Anyone asking you to “verify” by sending coins first → no.
  • This desk holds 0 keys. We cannot recover a seed we never had.
