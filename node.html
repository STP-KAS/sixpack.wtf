How to — kaspa bot (mainnet operator)

  1. Grok Bot → new agent. Name it kaspa bot.
  2. Paste the block from Xai.Kaspa.node START.md and send.
  3. Let it work. Do not interfere. It reports when the node is up.
  4. Check public: kaspa.stream/nodes (map can lag) and arewepublicyet.com.

Node runs on the Grok Bot Linux sandbox, not on your phone. RPC stays private. Only P2P 16111 is public. Pin: rusty-kaspa v2.0.1.

Home-PC public node (inbound TCP 16111, RPC on localhost): windows-p2p-node-guide.

How to — tn10 bot (wallet + miner)

  1. Grok Bot → Create new Bot. Not kaspa bot. Name it tn10 bot.
  2. Paste the block from groks-wallet START-TN10.md and send.
  3. Mine only to kaspatest:qzffl5…v0ldx. Do not generate a new seed. Do not mine mainnet.
  4. Leave kaspa bot alone. Different ports, different datadir.

TN10 P2P is 16211. Mainnet is 16111. Mixing those is how you break both nodes.
