How to — kaspa bot (mainnet operator)

  1. Grok Bot → new agent. Name it kaspa bot.
  2. Paste the block from Xai.Kaspa.node START.md and send.
  3. Let it work. Do not interfere. It reports when the node is up.
  4. Check public: kaspa.stream/nodes (map can lag) and arewepublicyet.com.

How Grok mines that wallet

  1. Grok Bot → Create new Bot. Name it tn10 bot. Not kaspa bot (kaspa bot is mainnet, no miner).
  2. Paste START-TN10.md and send. It fetches GROK_BOT_PROMPT_TN10.md.
  3. Bot starts Testnet-10 kaspad (P2P 16211, gRPC localhost 16210) and kaspa-miner CPU threads.
  4. Pay-to is locked: kaspatest:qzffl5xy9np46gkttyuftqnv2w04pr8g3wsp7c3vv8se3txtelx6q7c0v0ldx. Do not generate a new seed. Do not mine mainnet.
  5. Leave kaspa bot alone. Different ports, different datadir.
