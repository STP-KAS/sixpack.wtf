1984 economics

This page is an experiment. Nothing here is really useful.

Funded test addresses

One thousand Testnet-10 addresses. Each one was sent 2,000 tKAS. tKAS is Testnet-10 KAS, the coin on this network. With tKAS you can go to the bank. The gate on 1984 takes a funded address. The same browser gets the same funded wallet. Wallet sign-in comes later.

The address and the transaction that funded it are on the funded list. That page stays short: search, or open forty lines at a time. The same file is on GitHub. The balance on each line is read again every 12 hours.

What the square is

1984 is a village square on Testnet 10. The town on the page is Ashfields. You walk in, you pay at a counter, and the books sit in this square’s own ledger. The spend gate stays shut.

How a payment works

Every payment on the square shows its steps, then the transaction, on the page. The steps are: the page asks, you pay, the receipt is written, and it is done. When it finishes you can open the transaction, or start a new purchase. A buy can be repeated.

A shop, a cinema ticket, a snack, a hop, or a Hunt Hall promise asks on the page, then OK. That buy is this square's ledger. tKAS is Testnet-10 KAS, the coin that moves. With tKAS you can go to the bank and swap it for a ledger tag. That lock is a Testnet 10 transaction. After it is seen, this ledger writes the tag. A funded test address can lock tKAS now. Wallet sign-in comes later.

Three rails, labeled, not welded. KAS is the coin that moves. On this square that label is tKAS. PoC kUSD is POCencept stable, a tag in this village ledger, not a dollar. The Tether-like rail is KUSDT stable, the other tag, and it can be frozen. A POCencept stable or KUSDT stable buy has a receipt id on this ledger and no Layer-1 transaction. A tKAS payment that has a txid is the Testnet 10 transaction. Open it on the Testnet 10 explorer. Liquidity records the promise and spends nothing on any rail.

The miner fee is always KAS. That is the mining coin. On this square that fee is six times the standard Testnet 10 rate, and it is extra. The fee is not POCencept stable and it is not KUSDT stable.

The same three are on every counter, the ticket, the snacks, a hop, and every row in Hunt Hall. tKAS only locks at the bank. POCencept stable redeems and holds the practice purse. KUSDT stable is the only booth with a freeze. A freeze blocks only KUSDT stable.

The roadster stays 1.00 on this ledger. If you already have it, another buy of the keys charges again and the car stays yours.

The spending rules

Each address can set a daily cap, a shop list, a rail list, and a confirm line. An empty list means every shop and every rail. The page checks the rule before it moves a balance. Those rules are a stand-in you chose. They live on this page.

Covenant, SilverScript, and a vProg step

A covenant would enforce a rule on Testnet 10 without trusting this page. SilverScript is covenants on Kaspa. Kaspero Labs showed a freelancer sheet: the chain holds the coins until a milestone is notarized, and the studio does not hold the funds. That sheet is on the bench. This page does not attach a covenant to a buy. A shop buy is this square’s own ledger. No covenant is attached, so there is no covenant tx. It is not Argent or SilverScript.

Argent is the language beside SilverScript. It is still not a tagged product. This page does not treat that demo as a shop rail.

BitCoffee’s covenant KUSD is a different object and is not minted here. PegLab’s quote is an outside price. If it moves, a redeem can fail because the lock no longer covers the tagged amount. That is a peg failing. It is not a promise of dollars.

A vProg guest can sequence a step. The tic-tac-toe guest is that kind of step: a game on the early vProgs prototype, not a payment rail. This square does not claim a shop spend is that step. It does not settle a coffee inside a tic-tac-toe match.

A bank tKAS lock is a Testnet 10 transaction. The txid is the payment. It is not an Argent or SilverScript covenant, and it is not a vProg tic-tac-toe ply. The tag written after it is this square’s own ledger.

A lab beside the square

A lab sits beside this square. It is STP-KAS/kusdt-split. It is early development. It is not a dollar, and it is not this till.

The SilverScript lock has one entry, redeem. The holder signs. The first output pays that same key the full locked amount. The miner fee is another input. The script has no freeze and no blacklist. On 1 Oct 2026 the Kaspa script engine redeemed 1 tKAS to the holder and kept the fee on the other input. A skimmed output failed. A different recipient failed. A different key failed. Nothing was broadcast. There is no Testnet 10 transaction id.

A local program freezes only the KUSDT tag. A POCencept move in that same batch still lands. In the lab that move debits at once. On this square a promise waits for the snap. Using the tag as gas is refused. The program does not hold the coins, and it does not spend the lock. It is not Maxim’s tic-tac-toe guest, and it is not a vProg settlement.

KCC-20 on kccs main 3fbec524 is Last Call, not Final. The header has no Last-Call-Deadline. The state order is amount, owner, owner scheme, borrow scheme, borrow guard, extension commitment. A borrow has to increase the amount. A negative threshold counts as zero. The same extension commitment is one fungible class. The reference that merged with that text is argent-lang/kcc20-reference c8a08711. The master-file pin is 5d7dcc9 on a branch. Main of that file was not moved. The KCC-20 file still writes the name P2PKHHash. KCC-2 defines that value as unkeyed BLAKE3.

On this square a lock checks that increase. POCencept and KUSDT use different extension commitments, so a standard move cannot mix them. Freezing KUSDT changes its commitment, so frozen units are not the liquid units. A shop burn is not a standard transfer: the amount leaves. The bank lock mints a POCencept or KUSDT tag only after it locks tKAS. It is not the reference public mint, which splits a remaining supply with no deposit. This is still this square’s own ledger. No covenant is attached to a shop buy. KCC-20 is not Final, and there is still no spendable L1 stable. The spend gate stays shut.

Mint, on the 1984 side rail, is a different desk. What: a named token on this square’s ledger. It is not tKAS, not a dollar, and not a spendable Layer-1 coin. How: open a new name, mint more of an open name, or send some to another kaspatest address. A mint has to increase the holder’s amount. A send keeps the total. The name is hashed with unkeyed BLAKE3, and that hash is the extension. Why: a funded address can try those three options on Testnet 10 while KCC-20 is still Last Call. A cap of 0 means no cap. The names POC, POCencept, KUSDT, KAS, and tKAS stay the rails and cannot be opened here. No covenant is deployed.

The bill the rails are for

A coin you can only hold has done the vault. The rails exist so a person can pay a bill a stranger can receive: a car, an AI service, a game purchase, a rented service. Wide adoption is how many tills take the coin. The coin is for that spend.

1984 puts tKAS, POCencept stable, and KUSDT stable on one counter so that gap is visible. Those three are the classroom. A promise on that square does not buy the car, the service, the game, or the rental. A Hunt promise does not buy the car, the AI service, the game, or the rental. The longer note is CEILING.md. The spend gate stays shut.

The idea

The best case for crypto is stable money you can spend anywhere. The spend is Kaspa, and Kaspa is volatile, or the spend is a stable. Without that, the coin has no point. Peer to peer is the payment. One person pays another.

Five percent of this portfolio is crypto. A profit stays in crypto, in a stable position, to hold or to spend, rather than cashed out to fiat. The use is to spend it, and to use it, fast, anywhere.

Applications and the other utilities matter as much as the coin, and sometimes more. Kaspa needs both before it leaves the bubble. Proof of stake offers part of that spend. It does not offer what scalable proof of work offers. That is settled.

This page is still the classroom. POCencept stable and KUSDT stable are tags in this village. They are not that money.
